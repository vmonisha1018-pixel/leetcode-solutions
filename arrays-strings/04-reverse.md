# Reverse a String

## Problem
Reverse a string.

## Link
https://leetcode.com/problems/reverse-string/

## Approach
I find the length of the string and then print the characters from the last character to the first character.

This produces the reversed string.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)

## Notes
Tested locally with a normal string and checked that the characters are printed in reverse order.
