# Valid Anagram

## Problem
Given two strings, determine whether one string is an anagram of the other.

## Link
https://leetcode.com/problems/valid-anagram/

## Approach
I compare the characters in both strings and check whether they contain the same characters with the same frequencies.

If the character counts match, the strings are anagrams.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(n)

## Notes
Tested locally with typical and non-anagram inputs.
