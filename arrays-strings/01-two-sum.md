# Two Sum

## Problem
Given an array of integers and a target value, find two numbers that add up to the target.

## Link
https://leetcode.com/problems/two-sum/

## Approach
I check the elements of the array and find two values whose sum is equal to the target value.

When the required pair is found, their indices are returned.

## Complexity
- Time Complexity: O(n²)
- Space Complexity: O(1)

## Notes
Tested locally with typical input values and checked that the correct pair of indices is found.
